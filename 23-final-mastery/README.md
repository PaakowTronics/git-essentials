# 23 — Final Git Mastery Challenge

## Outcomes

Demonstrate independent ability across Linux navigation, documentation, Git state, commits, branches, remotes, collaboration, conflicts, recovery, debugging, and verification.

## Exam setup

Start with a fresh Linux environment and a prepared challenge repository. Provide only the repository/documentation and task statement.

## Part 1

Identify OS, architecture, current directory, and project location.

## Part 2

Read project documentation, identify prerequisites, install/configure what is needed, and verify.

## Part 3

Inspect repository state, branches, history, and remotes.

## Part 4

Implement a feature on a new branch with logical commits.

## Part 5

Integrate simulated teammate changes. Resolve a conflict if created.

## Part 6

Recover from a controlled mistake without losing legitimate work.

## Part 7

Use history to locate a deliberately introduced regression.

## Final reflection

Return to the learner's first-day definition of Git. Explain how their understanding changed and describe how they would approach an unfamiliar Git problem now.

## Check guidance

Mastery requires independent diagnosis and verification. A learner who needs a command-by-command recipe has not yet reached the intended standard.
