# Git Essentials Quick Reference

This is a reference, not a substitute for the lessons.

## Inspect
```bash
pwd
ls
git status
git log
git log --oneline
git show
git diff
git remote -v
git branch
```

## Core
```bash
git init
git clone
git add
git commit
git switch
git merge
git fetch
git pull
git push
```

## Recovery / advanced
```bash
git restore
git revert
git reset
git reflog
git stash
git rebase
git cherry-pick
git tag
git bisect
```

Learners should use `git help <command>` and official documentation when they need details.
