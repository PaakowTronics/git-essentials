# 08 — Branches

## Outcomes

- create and switch branches;
- understand branch pointers;
- understand HEAD;
- isolate feature work.

## Mental model

A branch is a movable name pointing to a commit. HEAD identifies what you currently have checked out, typically through a branch reference.

## Guided lab

Create `main` history, create a feature branch, make two commits, switch back, and observe the working tree.

## Practice drills

- create a branch;
- switch branches;
- inspect branches;
- compare branch tips;
- create a feature without changing main.

## Break-It lab

Create an unfinished feature on a branch. Switch to main and confirm what is and is not present. Then return to the feature.

## Challenge

Draw the commit graph before and after a feature branch receives two commits.

## Assignment

Create `feature/login`, make two meaningful commits, return to main, prove the work is isolated, then prepare the branch for merge.

## Check guidance

Learner should explain branch isolation without saying that branches are complete physical copies of the repository.
