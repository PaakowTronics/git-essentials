# 18 — Cherry-Pick

## Outcomes

- understand selective commit transfer;
- cherry-pick a useful commit;
- resolve a cherry-pick conflict;
- verify resulting history.

## Guided lab

Create two branches. Make an isolated useful commit on one. Cherry-pick it onto the other. Inspect the resulting history and commit identity.

## Practice drills

- single commit;
- conflict during cherry-pick;
- aborting a problematic cherry-pick in a disposable lab;
- verify final content.

## Challenge

Explain why cherry-picking creates a new commit in the destination history rather than simply moving the original commit.

## Assignment

Complete a selective-fix scenario where only one commit from a feature line belongs on another branch.

## Check guidance

Look for understanding of selective integration and the need to verify the resulting content.
