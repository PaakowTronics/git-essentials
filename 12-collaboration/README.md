# 12 — Collaboration

## Outcomes

- work with feature branches;
- use pull requests;
- update work after review;
- understand team-oriented branch practices.

## Guided lab

Simulate two contributors. Each creates a feature branch, commits, pushes, opens a pull request, receives a change request, updates, and merges.

## Practice drills

- branch naming;
- pull request creation;
- responding to review;
- updating a branch;
- deleting a merged branch where appropriate.

## Challenge

Evaluate a proposed workflow that has everyone committing directly to main. Identify risks and circumstances that might make different workflows reasonable.

## Assignment

Complete a two-person GitHub workflow from issue/task to merged pull request. Preserve the evidence in the repository history.

## Check guidance

Assess whether the learner understands collaboration as a workflow, not merely as a list of GitHub buttons.
