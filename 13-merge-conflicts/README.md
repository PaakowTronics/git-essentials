# 13 — Merge Conflicts

## Outcomes

- understand why conflicts happen;
- read conflict markers;
- resolve deliberately;
- verify after resolution.

## Mental model

A conflict means Git cannot safely combine competing changes automatically. It is a request for a human decision.

## Guided lab

Create two branches that change the same lines differently. Merge them and inspect the conflict markers.

## Practice drills

Create conflicts involving:
1. same line;
2. nearby lines;
3. edit versus deletion.
Resolve each deliberately.

## Break-It lab

Create a conflict, then inspect status before editing anything. Identify every conflicted file first.

## Challenge

Resolve a conflict without blindly choosing "ours" or "theirs." Explain the business/content reason for the final version.

## Assignment

Complete three conflict scenarios and submit a short incident report for each: cause, evidence, resolution, verification.

## Check guidance

A correct resolution must be logically correct, staged/completed as required, and verified. Merely making Git say 'resolved' is insufficient.
