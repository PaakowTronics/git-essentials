# Merge Conflicts — Lab Environment

This directory is reserved for the disposable lab repository used by this lesson.

## Safety

Perform destructive exercises only inside this lab.

Do not run reset, rebase, deletion, force-push, or package installation experiments against important repositories.

## Lab setup

The lab may be generated or populated by an instructor.

When automation is added, it should verify repository state and outcomes rather than checking for a single exact command.
