# Undoing Changes — Answer / Check Guidance

This file is for instructors or learners checking their own work.

## Principle

There may be multiple valid command sequences. Evaluate the **result, reasoning, and verification**, not command memorization.

## Minimum standard

The learner should be able to:
- describe the initial state;
- describe the desired state;
- identify the evidence used;
- perform a valid operation;
- verify the result;
- explain what happened.

## Instructor prompt

If the learner is stuck, ask:
1. What state are you in?
2. What does Git report?
3. What does the documentation say?
4. What result are you trying to reach?
5. How can you verify the result?

Do not reveal the answer immediately.
