# 07 — Reading Git History

## Outcomes

- read commit history;
- inspect a specific commit;
- compare revisions;
- use history as evidence.

## Guided lab

Use the five-commit project. Explore:
```bash
git log
git log --oneline
git show
git diff
```
Determine what changed in a selected commit.

## Practice drills

1. Identify the latest commit.
2. Identify an earlier commit.
3. Inspect a commit.
4. compare two points in history.
5. Write a project timeline from the history.

## Challenge

Repository archaeology: you inherit a project and are asked, "What happened over the last five commits?" Produce a factual timeline using Git evidence.

## Assignment

Create a repository with at least eight meaningful commits. Give another learner three questions that can only be answered by investigating the history.

## Check guidance

Full credit requires evidence-based answers. Penalize guesses presented as facts.
