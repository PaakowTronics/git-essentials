# 22 — Documentation Missions

## Outcomes

- independently install a developer tool;
- read an unfamiliar README;
- troubleshoot documentation/setup problems;
- distinguish authoritative documentation from secondary sources.

## Mission A

Install a legitimate developer tool from its official Linux documentation. Submit OS, architecture, prerequisites, installation method, verification, and version.

## Mission B

Clone a legitimate GitHub project with a clear README and set it up from scratch.

## Mission C

Compare official documentation with a third-party tutorial for the same software. Identify version, platform, and safety differences.

## Mission D

Investigate a real setup error. Record symptom, hypothesis, documentation consulted, fix, and verification.

## Challenge

You are given only a repository URL and a Linux terminal. Get the project running using its documentation. No instructor command list.

## Assignment

Complete all four missions and produce a professional setup report.

## Check guidance

Full mastery requires independent documentation discovery, careful execution, troubleshooting, and verification.
