# 19 — Tags & Releases

## Outcomes

- identify stable points with tags;
- inspect tags;
- connect tags to GitHub releases;
- understand version identification.

## Guided lab

Create a small history, tag a stable point, add more work, then compare the tagged point with current history.

## Practice drills

- list tags;
- inspect a tag;
- identify the commit a tag references;
- create a GitHub release from a practice tag.

## Challenge

Explain why a named release point can be easier for humans to communicate than a long commit hash.

## Assignment

Create a practice versioned project with at least two tagged milestones and a GitHub release for one.

## Check guidance

Verify that tags identify the intended commits and release documentation matches the repository state.
