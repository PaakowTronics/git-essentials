# 21 — Real-World Git Workflows

## Outcomes

- combine multiple Git skills;
- choose a workflow based on a task;
- preserve work during interruptions;
- prepare changes for review.

## Mission A

Implement a fictional password-reset feature from a task description. No command list.

## Mission B

An urgent bug appears while your feature is incomplete. Preserve your work, switch context, fix the bug, and return safely.

## Mission C

A shared branch contains an undesirable commit. Investigate and propose a safe team response.

## Mission D

Clone an unfamiliar open-source project and follow its README to set it up. Record prerequisites, commands used, and verification.

## Assignment

Complete one end-to-end feature workflow and one interruption/recovery workflow. Explain every major Git state transition.

## Check guidance

Grade decision-making, verification, and safety—not command speed.
