# Git Essentials — Progress Tracker

## How to Use This Tracker

Do not use this document as a simple attendance sheet.

A completed lesson does not automatically mean a mastered skill.

For each skill, mark the learner's current level:

- **N — Not Introduced:** The learner has not encountered the skill.
- **E — Exposed:** The learner has seen the skill and can follow an example.
- **P — Practising:** The learner can perform it with some guidance.
- **C — Capable:** The learner can perform it independently in a familiar situation.
- **I — Independent:** The learner can apply it in an unfamiliar situation and recover from mistakes.

The final goal is not “all lessons completed.”

The final goal is **Independent** across the core skills.

# Final Independence Check

Before declaring the course complete, ask the learner to demonstrate all of these without a command-by-command script:

- [ ] Enter an unfamiliar repository.
- [ ] Explain where they are.
- [ ] Inspect the repository state.
- [ ] Inspect recent history.
- [ ] Identify the current branch.
- [ ] Create isolated work.
- [ ] Make and commit a change.
- [ ] Integrate work.
- [ ] Resolve a conflict.
- [ ] Recover from an intentional mistake.
- [ ] Use documentation when unsure.
- [ ] Explain what they did.
- [ ] Verify the final repository state.

If several boxes require instructor commands, the learner is still developing independence.

## Final evidence

A learner should not be marked complete merely because all 23 lessons are checked off. The strongest evidence comes from the final assessment: the learner can enter the prepared repository, investigate what they find, make appropriate decisions, recover from a problem, and explain how they know the final state is correct.
