# Instructor Guide

## How to use this repository

The course is designed for self-study, instructor-led training, or a hybrid.

A learner should have:

- a Linux environment
- Git
- a GitHub account
- terminal access
- a text editor
- internet access for documentation missions

## Do not give away the answer too early

When a learner is stuck, ask:

1. What are you trying to achieve?
2. What does `git status` say?
3. What does the documentation say?
4. What changed?
5. What would you expect to happen?
6. How could we verify that?

Only provide the exact command when the learner has exhausted investigation.

## Assessment principle

A learner who can reproduce a command but cannot explain the repository state has not demonstrated mastery.

A learner who uses a different valid command and reaches the correct, verified state should receive credit.

## Safety

Destructive exercises should happen in disposable lab repositories.

Never instruct learners to experiment with `reset`, rebase, force push, deletion, or package installation against important production repositories or systems.
