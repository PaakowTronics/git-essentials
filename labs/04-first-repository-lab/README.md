# Lab 04 — First Git Repository

## Mission

Create a small project and turn it into a Git repository without creating a commit.

Create:

```text
mountain-cafe/
├── README.md
├── menu.txt
└── hours.txt
```

## Requirements

1. Confirm your terminal location before starting.
2. Confirm the three project files exist.
3. Check whether the folder is already a Git repository.
4. Predict what `git init` will do.
5. Initialize Git.
6. Verify that `.git` exists.
7. Run `git status`.
8. Confirm the three project files are untracked.
9. Explain why they are untracked.
10. Confirm that no commit has been created yet.

## Outcome Check

The learner should be able to explain:

- what `git init` did
- what `.git` represents
- why `git status` reports the files
- why initialization did not create a commit

## Important

Do not add or commit the files in this lab. The next lessons will deliberately build on this state.
