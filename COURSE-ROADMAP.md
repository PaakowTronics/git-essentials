# Git Essentials — Course Roadmap

## Why the Course Was Restructured

The original course was organized primarily around Git topics.

The rebuilt course is organized around **learner readiness**.

A beginner should not be asked to understand a new concept simply because it appears next in a topic list. Each lesson should build on skills already established.

The progression is therefore:

```text
Learn the terminal
        ↓
Learn how to find reliable instructions
        ↓
Understand Git
        ↓
Create a repository
        ↓
Understand Git's view of changes
        ↓
Record meaningful history
        ↓
Investigate history
        ↓
Compare versions
        ↓
Branches
        ↓
Merging
        ↓
GitHub
        ↓
Collaboration
        ↓
Conflicts
        ↓
Recovery
        ↓
Advanced Git
        ↓
Independent problem solving
```

## Naming Convention

Each lesson directory uses:

```text
NN-short-descriptive-name/
```

Each completed beginner-facing lesson uses the same two primary files:

```text
README.md
practice-drills.md
```

The course intentionally avoids multiplying small lesson files when the learner can work more effectively from one detailed lesson and one dedicated practice-drill file.
