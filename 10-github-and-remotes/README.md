# 10 — GitHub & Remote Repositories

## Outcomes

- create/use a GitHub repository;
- connect a local repository to a remote;
- push commits;
- distinguish local and remote state.

## Guided lab

Create a practice GitHub repository. Connect it to the local project. Inspect the remote configuration. Push a meaningful history. Verify on GitHub.

## Practice drills

- inspect remotes;
- push a branch;
- create a remote branch;
- verify local versus remote state;
- clone a repository into a second directory.

## Challenge

Make a local commit. Explain why it may not yet appear on GitHub. Then push and verify.

## Assignment

Publish a five-commit local project to GitHub. Submit evidence of remote configuration and the GitHub history.

## Check guidance

Do not require a specific authentication method. SSH and HTTPS can both be valid depending on the learner's environment and current GitHub guidance.
