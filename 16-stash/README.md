# 16 — Stash

## Outcomes

- temporarily store unfinished changes;
- inspect stash entries;
- restore work deliberately;
- understand when a temporary commit may be better.

## Guided lab

Begin a feature, create unfinished changes, stash them, handle an urgent task, then restore the feature work.

## Practice drills

- create a stash;
- inspect stash list;
- restore without immediate deletion;
- restore and remove when appropriate;
- verify content.

## Challenge

Decide whether stash or a temporary commit is more appropriate for three different scenarios. Explain why.

## Assignment

Complete an interruption-and-return simulation and prove that the unfinished work survived.

## Check guidance

The learner should understand stash as a temporary storage mechanism, not a substitute for all commits.
