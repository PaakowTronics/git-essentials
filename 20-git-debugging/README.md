# 20 — Debugging With Git

## Outcomes

- use history as debugging evidence;
- identify a regression;
- use bisect for a reproducible problem.

## Guided lab

Create at least eight commits and deliberately introduce a bug in the middle. Use history inspection first, then `git bisect`.

## Practice drills

- compare known-good and bad states;
- inspect candidate commits;
- run a reproducible test;
- bisect;
- verify the first bad commit.

## Challenge

Explain why meaningful, focused commits make historical debugging easier.

## Assignment

Complete a regression investigation and submit the first-bad commit, evidence, and a short explanation.

## Check guidance

The learner must define a reliable good/bad test before bisecting. Guessing defeats the purpose.
